Datenschutz

VereinsCheck ist ein Werkzeug, das die Datensicherheit von Vereinswebsites prüft. Es wäre widersprüchlich, dabei selbst Daten zu sammeln — deshalb tun wir es nicht.

Kurz und klar: VereinsCheck speichert nichts.

Keine eingegebenen URLs, keine Scan-Ergebnisse, keine IP-Adressen, keine Cookies. Jede Anfrage wird vollständig im Arbeitsspeicher verarbeitet und danach verworfen. Es gibt keine Datenbank.

Was passiert bei einem Scan?

Wenn du eine Website-Adresse eingibst und auf „Jetzt prüfen" klickst, stellt VereinsCheck im Hintergrund eine Verbindung zur eingegebenen Website her — genau wie es ein Browser tun würde. Die dabei gesammelten technischen Daten (z.B. welche Sicherheits-Header gesetzt sind) werden ausgewertet und sofort als Ergebnis angezeigt.

Danach werden alle Daten gelöscht. Es werden keine Logs geschrieben, keine Einträge gespeichert, keine Statistiken erhoben.

Was VereinsCheck nicht tut

Datentyp Wird gespeichert?
Eingegebene URL ✓ Nein
Scan-Ergebnisse ✓ Nein
IP-Adresse des Nutzers ✓ Nein
Cookies ✓ Nein
Tracking (Google Analytics etc.) ✓ Nein
Nutzerkonten / Registrierung ✓ Nein

Externe Verbindungen

Beim Laden dieser Seite werden Google Fonts (Lexend, Source Sans 3) von fonts.googleapis.com geladen. Das ist die einzige externe Verbindung. Dabei überträgt dein Browser eine Anfrage an Google, was mit einer IP-Adresse verbunden ist. Wenn du das vermeiden möchtest, kannst du die Seite im Browser mit deaktiviertem JavaScript oder über einen Font-Blocker nutzen — die Funktion des Scanners wird davon nicht beeinträchtigt.

PDF-Bericht

Der herunterladbare PDF-Bericht wird vollständig auf dem Server erstellt und direkt an deinen Browser übertragen. Er wird nicht gespeichert. Du kannst ihn anschließend lokal speichern und weiterleiten.

Open Source

VereinsCheck ist vollständig Open Source (MIT-Lizenz). Der gesamte Quellcode ist auf GitHub einsehbar — damit kannst du selbst prüfen, was die Software tut und was nicht.
